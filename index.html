Home Energy Codes API

家庭の省エネ診断アプリ向けの基本マスタデータ(診断項目 / 省エネ対策項目)を提供する、読み取り専用の静的JSON APIです。

認証不要 CORS許可 静的ホスティング(GitHub Pages)

エンドポイント

GET /api/v1/input.json — 診断の入力項目(質問と選択肢)一覧
GET /api/v1/measures.json — 省エネ対策項目一覧
GET /api/v1/cons.json — 消費量カテゴリ(cons)のマスタ。input.jsonのcons、measures.jsonのrefConsから参照される
GET /api/v1/energy.json — エネルギー種別(電力・都市ガス・灯油など)のマスタ
GET /api/v1/energycost.json — エネルギー種別ごとの料金項目コードのマスタ
GET /api/v1/applianceCategory.json — 機器カテゴリー(自動車・テレビ・冷蔵庫・給湯器など)のマスタ
GET /api/v1/equips.json — 機器マスタ(大分類/中分類/小分類と親子関係、エネルギー区分)の一覧
GET /api/v1/meta.json — 件数・生成日時などのメタ情報
GET /input/saved-input.schema.json — 保存データ(JSON)の機械可読スキーマ(JSON Schema)
GET /input/saved-input-format.md — 保存データ(JSON)の定義と解説
GET /api/v1/input.csv — input.json の元CSV(生データ)
GET /api/v1/measures.csv — measures.json の元CSV(生データ)
GET /api/v1/cons.csv — cons.json の元CSV(生データ)
GET /api/v1/energy.csv — energy.json の元CSV(生データ)
GET /api/v1/energycost.csv — energycost.json の元CSV(生データ)
GET /api/v1/applianceCategory.csv — applianceCategory.json の元CSV(生データ)
GET /api/v1/equips.txt — equip.json の元データ(生テキスト)

使い方

fetch("https://hinodeyasuzuki.github.io/homeenergycodes-public/api/v1/input.json")
  .then(res => res.json())
  .then(items => console.log(items));

すべてのレスポンスはCORSヘッダ(Access-Control-Allow-Origin: *)付きで配信されるため、ブラウザから直接どのオリジンからでも取得できます。

input.json のフィールド

フィールド説明
id項目ID(例: i001)
title項目名
cons紐づく消費量カテゴリキー
unit単位(空の場合あり)
text質問文
inputType入力タイプ識別子(sel*** = 選択式、text = 自由記述)
options選択肢の配列 {disp, val}。val:-1 は「選んで下さい」の未選択プレースホルダー

options が空配列の項目(都道府県など)は、選択肢が別マスタ(都道府県リスト等)から動的に供給される想定の項目です。
note フィールドがある項目は、元データの不整合(壊れたExcel参照 #REF!)を text 型に補正したことを示します。

measures.json のフィールド

フィールド説明
mid対策ID(数値)
name対策の内部名
title対策の説明文
refCons対象となる消費量カテゴリキー
titleShort短縮タイトル
easyness取り組みやすさスコア
levelレベル(未設定はnull)
figNum関連図番号
lifeTime耐用年数。多くは年数(数値)だが、一部機器は使用時間(例: "40000h")の文字列
price概算費用(円)
season関連季節キー

cons.json のフィールド

フィールド説明
codeカテゴリキー(input.jsonのcons、measures.jsonのrefConsと対応)
shortcode短縮コード(未設定はnull)
titleカテゴリ名
countgroup集計グループ(未設定はnull)
sumclass親カテゴリのcode。ルートカテゴリはnull

energy.json / energycost.json のフィールド

フィールド説明
codeコード(例: elect / electp)
name名称(例: 購入電力 / 購入電力料金)
unit単位(energy.jsonのみ。例: kWh, m3, L)

energycost.jsonのcodeはenergy.jsonのcodeに接尾辞p(price)を付けた対応関係になっています(例: elect ⇔ electp)。

applianceCategory.json のフィールド

フィールド説明
codeコード
title名称
cons対応するcons.jsonのcode

equip.json のフィールド

フィールド説明
id機器ID(文字列)
title機器名
level階層レベル(1:大分類, 2:中分類, 3:小分類)
parentId親項目のID。大分類はnull
level1Id所属する大分類ID
level2Id所属する中分類ID。大分類はnull
energyFlagエネルギー区分(1/2)。空の場合は上位カテゴリから継承した解決済み値

equip.jsonはequips.txtをもとに、階層とエネルギー区分の継承を解決した配列です。 入力アプリではこの階層情報を使って段階選択UI(大分類→中分類→小分類)を構築できます。

更新方法

このAPIは input.csv / measures.csv を正データとし、build.py で docs/api/v1/ 配下のJSONを生成しています。CSVを更新した場合は python3 build.py を再実行してからコミット・公開してください。

保存形式(JSON)の定義

入力アプリが保存/エクスポートするJSON形式は、次の2つで公開しています。

  • /input/saved-input-format.md — 人が読むための定義と解説
  • /input/saved-input.schema.json — ツールで検証するためのJSON Schema
